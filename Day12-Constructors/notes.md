# Day 12 - Constructors

- Same name as the class, no return type.
- If you write none, Java gives a default no-arg constructor; if you write any, it doesn't.
- `this.field = field` separates the field from the parameter; `this(...)` chains constructors.
- A copy constructor builds a new object from an existing one.

## Run
```bash
javac Main.java
java Main
```
