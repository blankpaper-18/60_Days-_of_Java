# Day 30 - Mini Project: Student Management with File Persistence

- Combines classes, validation, `Map`, streams, `Optional`, exceptions and file I/O.
- Data is saved as CSV in `data/students.csv` and reloaded by a fresh manager.
- Ideas to extend: update by name, import/export, a console menu on top.

## Run
```bash
javac Main.java
java Main
```
