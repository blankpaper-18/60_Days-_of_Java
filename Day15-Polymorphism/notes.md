# Day 15 - Polymorphism

- Compile-time: overloading. Runtime: overriding.
- A parent reference can hold a child object; the child's overridden method runs.
- `instanceof` with a pattern (`s instanceof Circle c`) checks and casts in one step.
- Fields are NOT polymorphic, only instance methods.

## Run
```bash
javac Main.java
java Main
```
