# Day 8 - Strings

- Strings are immutable; every 'change' creates a new String.
- Always compare with `.equals()`, never `==`.
- Use `StringBuilder` for building strings in loops.
- Handy: `substring`, `indexOf`, `split`, `join`, `trim`, `strip`, `repeat`, `format`, `isBlank`.
- Text blocks (`"""`) make multi-line strings easy.

## Run
```bash
javac Main.java
java Main
```
