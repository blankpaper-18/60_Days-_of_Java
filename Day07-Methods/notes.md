# Day 7 - Methods

- Parts: modifiers, return type, name, parameters, body.
- Overloading = same name, different parameter lists.
- Varargs (`int... values`) arrive as an array.
- Java is always pass-by-value (for objects, the value is a copy of the reference).
- Recursion needs a base case; plain `fibonacci(n)` is exponential, so avoid it for big `n`.

## Run
```bash
javac Main.java
java Main
```
