# Day 20 - Mini Project: Library Management System

- Pulls together classes, encapsulation, inheritance (`Item` -> `Book`), an enum for status, an interface (`Searchable`) and static members.
- All data lives in memory; restarting the program resets it (Day 30 adds file saving).
- Ideas to extend: due dates and fines, a `Member` search, reading the catalogue from a file.

## Run
```bash
javac Main.java
java Main
```
