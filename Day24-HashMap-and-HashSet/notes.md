# Day 24 - HashMap and HashSet

- `HashMap`: key to value, unordered, near O(1). `LinkedHashMap` keeps insertion order; `TreeMap` sorts keys.
- `HashSet` stores unique values; `add` returns `false` for a duplicate.
- `merge(word, 1, Integer::sum)` is the neat way to count things.
- Keys used in hash collections need correct `equals` and `hashCode`.

## Run
```bash
javac Main.java
java Main
```
