# Day 19 - Enums and Inner Classes

- Enums are a fixed set of constants; they can have fields, constructors and methods.
- `values()`, `valueOf()`, `name()`, `ordinal()`; enums work great in `switch`.
- Inner class (non-static) needs an outer instance; static nested class does not.
- Local and anonymous classes live inside methods/expressions.

## Run
```bash
javac Main.java
java Main
```
