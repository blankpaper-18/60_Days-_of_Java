# Day 17 - Interfaces

- A pure contract; a class can implement many interfaces.
- `default` and `static` methods allow evolving interfaces without breaking implementers.
- A functional interface has one abstract method and can be implemented with a lambda.
- Interface fields are implicitly `public static final`.
- Abstract class vs interface: state and shared code vs capability / multiple inheritance of type.

## Run
```bash
javac Main.java
java Main
```
