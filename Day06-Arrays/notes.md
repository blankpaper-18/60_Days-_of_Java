# Day 6 - Arrays

- Fixed size, zero-indexed, `array.length` (a field, not a method).
- Defaults: numbers `0`, boolean `false`, objects `null`.
- `Arrays.toString`, `sort`, `copyOf`, `fill`, `equals`, `binarySearch` (array must be sorted).
- 2D arrays are arrays of arrays, so rows can have different lengths (jagged).
- `arr == arr2` compares references; use `Arrays.equals` for contents.

## Run
```bash
javac Main.java
java Main
```
